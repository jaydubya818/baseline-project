# Title: Buyer Intent Score Calculation System
# Status: done
# Dependencies: 4, 10, 11, 13

# Description: Implement a real-time buyer intent scoring system that tracks and calculates buyer intent based on NDA signed status, profile completeness, message activity, and document access patterns.
# Details:
1. Create a BuyerIntentScore model and schema:
```typescript
interface BuyerIntentScore {
  id: string;
  userId: string;
  listingId: string;
  ndaSignedScore: number;
  profileCompletenessScore: number;
  messageActivityScore: number;
  documentAccessScore: number;
  totalScore: number;
  lastCalculated: Date;
}
```

2. Implement the BuyerIntentScoreService:
```typescript
class BuyerIntentScoreService {
  // Calculate score based on NDA status
  calculateNdaSignedScore(userId: string, listingId: string): Promise<number>;
  
  // Calculate score based on profile completeness
  calculateProfileCompletenessScore(userId: string): Promise<number>;
  
  // Calculate score based on message activity
  calculateMessageActivityScore(userId: string, listingId: string): Promise<number>;
  
  // Calculate score based on document access patterns
  calculateDocumentAccessScore(userId: string, listingId: string): Promise<number>;
  
  // Calculate total buyer intent score
  calculateTotalScore(userId: string, listingId: string): Promise<number>;
}
```

3. Create API endpoints for buyer intent score:
   - GET /api/listings/:id/buyer-intent
   - GET /api/users/:id/buyer-intent

4. Implement real-time score calculation triggers:
   - When NDA is signed
   - When profile is updated
   - When messages are sent/read
   - When documents are accessed

5. Create database indexes for efficient score retrieval:
```sql
CREATE INDEX idx_buyer_intent_user_listing ON buyer_intent_scores(userId, listingId);
CREATE INDEX idx_buyer_intent_listing ON buyer_intent_scores(listingId);
```

const SCORE_WEIGHTS = {
