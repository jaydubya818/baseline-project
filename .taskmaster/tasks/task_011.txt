## API Request/Response Schemas

### 1. Dealroom CRUD Endpoints

#### POST /api/dealrooms
Creates a new dealroom (typically via NDA acceptance flow).

Request Body:
```json
{
  "listingId": "clxyz123...",    // Required: cuid listing ID
  "acceptNda": true              // Required: must be true to create
}
```

Response (201 Created):
```json
{
  "success": true,
  "dealroomId": "clxyz456...",
  "fastTracked": false
}
```

Error Response (400/401/403):
```json
{
  "success": false,
  "error": "Only buyers can sign NDAs" | "Complete your buyer profile first" | "Listing not found"
}
```

Validation Rules:
- User must be authenticated (401 if not)
- User must have role=BUYER
- User must have canAccessNDA=true in BuyerProfile (OR isEliteBuyer=true for fast-track)
- Listing must exist and have status=ACTIVE
- User cannot create dealroom on own listing (sellerId !== user.id)
- Unique constraint: (listingId, buyerId) - no duplicate dealrooms

### 2. Messaging Endpoints

#### POST /api/dealrooms/:id/messages
Request Body:
```json
{
  "content": "Hello, I'm interested in learning more about the business.",
  "attachments": []  // Optional: array of document IDs
}
```

Validation Rules:
- content: string, required, 1-10000 characters, trimmed
- attachments: string[], optional. If present, every element MUST pass:
  1. Format check: each ID must match CUID format (regex: /^c[a-z0-9]{24}$/)
  2. Existence check: each ID must exist in the Document store (via getDocumentById or prisma.document.findMany)
  3. Membership check: each document.dealroomId must equal the target dealroom ID (req.params.id)
  - Any invalid format, non-existent ID, or cross-dealroom reference returns HTTP 400 with a clear error message
  - Invalid IDs are NOT silently omitted - validation fails the entire request
  - The validateAttachments() function performs existence and membership checks in a single query
- User must be buyer, seller, or assigned advisor for this dealroom

Response (201 Created):
```json
{
  "success": true,
  "message": {
    "id": "msg_abc123...",
    "dealroomId": "clxyz456...",
    "senderId": "buyer123...",
    "content": "Hello, I'm interested in learning more about the business.",
    "isRead": false,
    "readAt": null,
    "attachments": [],
    "createdAt": "2026-01-05T10:35:00.000Z",
    "sender": {
      "id": "buyer123...",
      "firstName": "John",
      "lastName": "Doe"
    }
  }
}
```

model Dealroom {
  id                String             @id @default(cuid())
  listingId         String             // FK to Listing
  buyerId           String             // FK to User (buyer)
  sellerId          String             // FK to User (seller)
  status            DealroomStatus     @default(DISCOVERY)
  // Enum: DISCOVERY, NDA_PENDING, NDA_SIGNED, INITIAL_REVIEW, DUE_DILIGENCE,
  //       NEGOTIATION, LOI_PENDING, LOI_SIGNED, UNDER_CONTRACT, CLOSED_WON, CLOSED_LOST
  ndaRequested      Boolean            @default(false)
  ndaRequestedAt    DateTime?
  ndaAccepted       Boolean            @default(false)
  ndaAcceptedAt     DateTime?
  loiSubmitted      Boolean            @default(false)
  loiSubmittedAt    DateTime?
  lastActivityAt    DateTime           @default(now())
  createdAt         DateTime           @default(now())
  updatedAt         DateTime           @updatedAt
  deletedAt         DateTime?          // Soft delete
  adminOwnerId      String?            // Optional admin assignment
  
  // Relations
  listing           Listing
  buyer             User
  seller            User
  messages          Message[]
  documents         Document[]
  activities        Activity[]
  
  // Unique: one dealroom per buyer-listing pair
  @@unique([listingId, buyerId])
  
  // Indexes for query performance
  @@index([listingId])
  @@index([buyerId])
  @@index([sellerId])
  @@index([status])
  @@index([lastActivityAt])
}
```

### Dealroom Access Matrix
| Action                                 | Buyer      | Seller     | Advisor    | Admin |
|----------------------------------------|------------|------------|------------|-------|
| View dealroom                          | ✅ (own)   | ✅ (own)   | ✅         | ✅    |
| Send message                           | ✅         | ✅         | ✅         | ✅    |
| Read messages                          | ✅         | ✅         | ✅         | ✅    |
| Upload document                        | ✅         | ✅         | ✅         | ✅    |
| Download document (requiresNDA=true)   | ✅ (NDA)   | ✅         | ✅         | ✅    |
| Delete document                        | ✅ (own)   | ✅ (own)   | ❌         | ✅    |
| Advance stage                          | ❌         | ✅         | ❌         | ✅    |
| Delete dealroom                        | ❌         | ❌         | ❌         | ✅    |

### Permission Check Implementation
```typescript
async function checkDealroomAccess(dealroomId: string, userId: string): Promise<{
  hasAccess: boolean;
  role: 'buyer' | 'seller' | 'advisor' | 'admin' | null;
}> {
  const dealroom = await prisma.dealroom.findUnique({
    where: { id: dealroomId },
    include: {
      managedDeal: {
        include: { advisor: { select: { userId: true } } }
      }
    }
  });
  
  if (!dealroom) return { hasAccess: false, role: null };
  if (dealroom.deletedAt) return { hasAccess: false, role: null };
  
  const user = await prisma.user.findUnique({ where: { id: userId } });
  if (!user) return { hasAccess: false, role: null };
  
  if (user.role === 'ADMIN') return { hasAccess: true, role: 'admin' };
  if (dealroom.buyerId === userId) return { hasAccess: true, role: 'buyer' };
  if (dealroom.sellerId === userId) return { hasAccess: true, role: 'seller' };
  if (dealroom.managedDeal?.advisor?.userId === userId) {
    return { hasAccess: true, role: 'advisor' };
  }
  
  return { hasAccess: false, role: null };
}
```

### Document Lifecycle & Retention
- Active dealrooms: Documents retained indefinitely
- Closed dealrooms (CLOSED_WON): Retained 7 years (legal compliance)
- Closed dealrooms (CLOSED_LOST): Retained 1 year, then purged
- Soft-deleted dealrooms: Documents retained 90 days before purge

### Signed URL Generation
```typescript
async function getDocumentAccessUrl(documentId: string, userId: string): Promise<string> {
  const doc = await prisma.document.findUnique({
    where: { id: documentId },
    include: { dealroom: true }
  });
  
  // Check access permissions
  if (!doc.dealroom && !doc.listing) {
    throw new Error('Document not associated with a dealroom or listing');
  }
  
  const access = await checkDealroomAccess(doc.dealroom.id, userId);
  if (!access.hasAccess) throw new Error('Unauthorized');
  
  if (doc.requiresNDA && !doc.dealroom.ndaAccepted && access.role === 'buyer') {
    throw new Error('NDA required to access this document');
  }
  
  // Generate signed URL (example with Vercel Blob)
  return await getSignedUrl(doc.fileUrl, { expiresIn: 3600 }); // 1 hour
}
