# Task ID: 29
# Title: Document Generation Engine with E-Signing Integration
# Status: done
# Dependencies: 2, 5, 10
# Priority: high
# Description: Implement a document generation engine that creates legal documents (NDA, LOI, Term Sheet) from templates with e-signing integration for digital signatures.
# Details:
1. Create a DocumentTemplate model and schema:
```typescript
interface DocumentTemplate {
  id: string;
  type: 'NDA' | 'LOI' | 'TERM_SHEET';
  name: string;
  content: string; // HTML/markdown with variable placeholders
  variables: string[]; // List of variable names used in template
  isDefault: boolean;
  createdAt: Date;
  updatedAt: Date;
}
```

2. Implement template storage and management:
   - Create a template repository in the database
   - Implement CRUD operations for templates
   - Add version control for templates with history tracking

3. Create document generation service:
```typescript
class DocumentGenerationService {
  async generateDocument(templateId: string, data: Record<string, any>): Promise<string>;
  async createPDF(htmlContent: string): Promise<Buffer>;
  async storeGeneratedDocument(documentType: string, listingId: string, content: Buffer): Promise<string>;
}
```

4. Implement e-signing integration:
   - Research and select e-signing provider (DocuSign, HelloSign, etc.)
   - Create an adapter interface for e-signing service
   - Implement authentication with the e-signing API
   - Create document signing request flow
   - Handle webhooks for signature status updates

5. Create document endpoints:
   - GET /api/templates (list available templates)
   - GET /api/templates/:id (get specific template)
   - POST /api/templates (create new template - admin only)
   - PUT /api/templates/:id (update template - admin only)
   - POST /api/documents/generate (generate document from template)
   - POST /api/documents/:id/sign (initiate signing process)
   - GET /api/documents/:id/status (check signing status)

6. Implement document versioning:
   - Track document versions with timestamps
   - Store all versions of generated documents
   - Provide access to document history

7. Create frontend components:
   - Template selection interface
   - Document preview component
   - Variable input form
   - E-signing initiation UI
   - Signature status tracking

8. Implement security measures:
   - Ensure documents are only accessible to authorized users
   - Implement encryption for document storage
   - Add audit logging for all document operations

9. Create integration with existing NDA system:
   - Connect to existing NDA gating logic
   - Ensure compatibility with NDA acceptance tracking
   - Extend the NDA model to support the new template system
