# Description: Create data models and API endpoints to store, retrieve, and calculate amortization schedules for seller financing deals, including payment schedules, principal/interest breakdowns, and payment history tracking.
# Details:
1. Create AmortizationSchedule model in Prisma schema:
   ```prisma
   model AmortizationSchedule {
     id          String   @id @default(uuid())
     listingId   String
     listing     Listing  @relation(fields: [listingId], references: [id])
     createdAt   DateTime @default(now())
     updatedAt   DateTime @updatedAt
     
     // Loan parameters
     loanAmount        Decimal
     interestRate      Decimal
     termMonths        Int
     paymentFrequency  String  // monthly, quarterly, etc.
     startDate         DateTime
     balloonPayment    Decimal?
     balloonMonths     Int?
     
     // Generated schedule
     payments          Payment[]
   }
   
   model Payment {
     id                  String   @id @default(uuid())
     amortizationId      String
     amortizationSchedule AmortizationSchedule @relation(fields: [amortizationId], references: [id])
     paymentNumber       Int
     paymentDate         DateTime
     paymentAmount       Decimal
     principalAmount     Decimal
     interestAmount      Decimal
     remainingBalance    Decimal
     isPaid              Boolean  @default(false)
     actualPaymentDate   DateTime?
     actualPaymentAmount Decimal?
   }
   ```

2. Create amortization schedule controller with the following endpoints:
   - POST /api/listings/:id/amortization - Create new amortization schedule
   - GET /api/listings/:id/amortization - Get all amortization schedules for a listing
   - GET /api/listings/:id/amortization/:scheduleId - Get specific amortization schedule
   - PUT /api/listings/:id/amortization/:scheduleId - Update amortization schedule
   - DELETE /api/listings/:id/amortization/:scheduleId - Delete amortization schedule
   - GET /api/listings/:id/amortization/:scheduleId/payments - Get all payments for a schedule
   - PUT /api/listings/:id/amortization/:scheduleId/payments/:paymentId - Update payment status
