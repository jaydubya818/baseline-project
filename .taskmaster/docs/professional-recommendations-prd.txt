# Professional Recommendations PRD
# SellerFi Platform Enhancement - 47 Recommendations Implementation

## Project Overview
This PRD defines the implementation of 47 professional recommendations across 8 categories to enhance the SellerFi platform's competitiveness, user satisfaction, and business outcomes.

## Technology Stack
- Next.js 16 (App Router)
- TypeScript
- PostgreSQL with Prisma
- shadcn/ui components
- Tailwind CSS
- Framer Motion for animations

## Priority Distribution
- Critical (8): Must complete first
- High (15): Complete in Phase 2
- Medium (14): Complete in Phase 3
- Low (10): Backlog/Phase 4

## PHASE 1: CRITICAL FIXES (8 Tasks)

### Task 1.1: Rate Limiting on Auth Endpoints [CRITICAL]
Implement Upstash Redis rate limiting on all authentication endpoints to prevent brute force attacks.
- Add @upstash/ratelimit package
- Create rate limiting middleware at lib/api/rate-limit.ts
- Apply to auth routes: app/api/auth/[...nextauth]/route.ts
- Limit: 5 attempts per minute per IP
- Return 429 status for exceeded limits
- Add tests for rate limiting behavior

### Task 1.2: Complete Photo Upload Implementation [CRITICAL]
Implement full image upload functionality for listings with proper storage integration.
- Create lib/services/image-upload.ts for Google Cloud Storage
- Add client-side resize before upload (max 2400px)
- Implement WebP conversion
- Create drag-and-drop upload component
- Add progress indicators
- Implement preview with crop/rotate functionality
- Enable image reorder capability
- Update listing creation and edit forms

### Task 1.3: Auto-Save for Listing Edit Form [CRITICAL]
Add auto-save functionality to the listing edit form to prevent data loss.
- Add useDebouncedCallback hook (3 second debounce)
- Create saveDraft API endpoint
- Show save status indicator (Saving.../Last saved X)
- Add useBeforeUnload warning for unsaved changes
- Sync with existing wizard auto-save pattern

### Task 1.4: Quick-Start Profile Flow [CRITICAL]
Create a streamlined two-tier profile system to reduce friction for NDA access.
- Create components/buyer/quick-profile-modal.tsx
- Implement 5-field quick profile: name, phone, capital range, industry interest, timeline
- Create extended profile for Elite features
- Show modal on first NDA attempt
- Store profile completion level in database
- Offer to complete extended profile later

### Task 1.5: Onboarding Email Sequence - Buyers [CRITICAL]
Implement automated drip email campaign for buyer onboarding.
- Day 0: Welcome + complete profile CTA

- Create email templates in lib/emails/buyer-onboarding/
